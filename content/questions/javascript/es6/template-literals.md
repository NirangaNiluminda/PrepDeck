## Question
What is a template literal, and how do you insert a value into one?

## Answer
A string written in **backticks** instead of quotes. `${expression}` inserts
the value of any expression at run time, and the string can span several
lines. For example, `` `<li>${color}</li>` `` instead of `'<li>' + color + '</li>'`.

## Key points
- backtick strings with ${expression} placeholders
- replaces string concatenation; can span lines
