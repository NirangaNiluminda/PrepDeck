## Question
A logged-in **non-admin** user tries to delete a movie, an action reserved for admins. Which status should the API return?

## Options
- [ ] 400 Bad Request
- [ ] 401 Unauthorized
- [x] 403 Forbidden
- [ ] 404 Not Found

## Answer
**403 Forbidden**: the server knows **who** you are (your token is valid),
but you aren't **allowed** to do this. **401 Unauthorized** (despite the
name) means **not authenticated**: no token, or an invalid or expired one.
"Log in, then try again."

On the backend this is typically two checks in a row: an **auth** middleware
(valid token? otherwise 401), then an **admin** middleware (role in the
claims? otherwise 403).

## Key points
- 401 = not authenticated (missing or invalid token)
- 403 = authenticated but not permitted
- authentication = who you are; authorization = what you may do
